# Security Policy

## Supported Versions

Security fixes are currently handled on the latest published version of pii-safe.

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report the issue privately through GitHub Security Advisories if available, or contact the maintainer through the repository owner profile.

Include:

- A short description of the issue.
- Steps to reproduce.
- The affected version.
- Any relevant input that triggers the issue.

Do not include real personal data, real tokens, or real credentials in reports.

## Scope

Security-sensitive issues include:

- Raw PII appearing in findings by default.
- Redaction bypasses for supported input types.
- Prototype pollution or unsafe object handling.
- Package supply-chain concerns.
- Published package contents that should not be included.
